# Smart Farming System

## Object-Oriented Programming in C++

The Smart Farming System is a console-based C++ application developed as an Object-Oriented Programming project at the University of South Asia. It aims to support better farming decisions by analyzing soil conditions and environmental factors to provide crop-related recommendations.

## Project Overview

The system allows users to register or sign in, select crop categories, enter soil and environmental information, and receive a structured farming analysis report.

## Key Features

- User registration and login
- Soil type validation for Sandy, Clay, and Loamy soils
- Temperature and moisture analysis
- Salinity assessment
- Crop selection and validation
- Fertilizer recommendations
- Estimated crop yield analysis
- Educational knowledge base covering agricultural concepts
- Input validation and user-friendly console navigation

## Crop Categories

- **Fruits:** Fruit crop selection and recommendations
- **Vegetables:** Vegetable crop selection and recommendations
- **Cereals:** Cereal crop selection and recommendations

## Object-Oriented Programming Concepts

- **Encapsulation:** Organizes user data and related parameters.
- **Abstraction:** Hides complex analysis logic behind user-facing results.
- **Inheritance:** Uses a common Crop class for specialized crop categories.
- **Polymorphism:** Supports category-specific behavior through method overriding.

## Technologies Used

- Programming Language: C++
- IDE: Dev-C++
- Standard Libraries: iostream, vector, and string
- Concepts: Object-Oriented Programming, input validation, and modular programming

## Limitations

The current implementation is console-based and stores user data temporarily during execution. It does not include permanent database storage, a graphical interface, or live environmental sensor integration.
